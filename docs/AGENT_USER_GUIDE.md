# AI 智能助手用户指南

## 概述

AI 智能助手（用户 ID: 10000，名称"AI智能助手"）是集成在聊天服务器中的 AI Agent，基于 LangChain + LangGraph 框架，通过 ZhipuAI/GLM-5 大模型驱动（通过 ModelScope API 调用），支持智能对话、联网搜索、查询服务器信息、代发消息等功能。

### 系统架构

```
用户（Windows/Linux 客户端）
  │
  ├── TCP/Protobuf ──→ ChatServer ──→ Python Agent Service（TCP Bridge）
  │                                            │
  │                                            ├── LangGraph（LLM 决策）
  │                                            │       └── ZhipuAI/GLM-5（ModelScope API）
  │                                            │
  │                                            └── MCP HTTP ──→ ChatServer（C++）
  │                                                              ├── 查好友/群组
  │                                                              ├── 查在线用户/统计
  │                                                              ├── 查用户信息
  │                                                              └── 代发消息
  │
  └── HTTP/REST ──→ Python Bridge（FastAPI :8000）
                     └── 提供 REST API 方便第三方集成
```

**关键设计**：
- **双通道通信**：消息收发走 TCP/Protobuf（实时高效），工具调用走 MCP HTTP（查询/操作）
- **AI 用户 ID 固定 10000**：每个注册用户自动添加 AI 为好友
- **消息防自循环**：AI 收到 fromid=10000 的消息直接丢弃
- **会话管理**：每个用户与 AI 的对话独立（thread_id = 用户 ID），支持连续多轮对话

## 功能列表

### 1. 日常闲聊

直接发送任意对话内容，AI 会用自然语言回复。

**示例**：
```
你好！
你叫什么名字？
今天天气怎么样？（会触发联网搜索）
```

### 2. 联网搜索

利用 Tavily 搜索引擎获取最新资讯。无需特定关键词，只要涉及"搜索"、"查一下"等意图即可触发。

**示例**：
```
搜索一下最近的科技新闻
帮我查查今天的热点话题
查一下 deepseek 的最新消息
```

### 3. 查看好友列表

查询当前用户的所有好友及其在线状态。

**示例**：
```
帮我看看我的好友列表
我有哪些好友？
查看我的好友
```

### 4. 查看群组信息

查询用户加入的群组列表，或查看指定群组的详细信息（成员、角色等）。

**示例**：
```
我加入了哪些群组？
查看群组1的信息
公共聊天室有哪些成员？
```

### 5. 查看在线用户

查询当前集群中所有在线用户。

**示例**：
```
现在哪些用户在线上？
看看服务器上有多少人在线？
谁在线？
```

### 6. 查看服务器统计

查询服务器连接数、在线用户数、软件版本等统计信息。

**示例**：
```
服务器状态怎么样？
当前服务器统计信息
```

### 7. 查询用户信息

按用户 ID 查询用户详情（名称、在线状态等）。

**示例**：
```
查一下用户393的信息
用户1000是谁？
```

### 8. 代发消息（核心功能）

让 AI 帮你给好友发送消息。AI 会**以你的身份**发送消息给指定好友。

**示例**：
```
请你帮我给我的好友393发送一条古风内容的表白信息
帮我给好友101发一条消息：晚上一起吃饭
给zzz发一句"生日快乐！"
请对好友393说今天天气真好
```

**功能细节**：
- AI 使用你的 `from_user_id` 发送消息，接收方看到的是你的名字
- 对方无论在线还是离线都能收到（离线则暂存，上线时推送）
- 可以指定消息风格（古风、幽默、正式等），AI 会生成相应内容
- 发送成功后 AI 会回复你一条确认消息，包含发送详情
- **无需提前加好友**：代发消息功能不校验好友关系，可以给任意用户发送

### 9. 综合指令

你可以把多个需求放在一句话里，AI 会依次处理。

**示例**：
```
帮我看看谁在线，然后给好友393发一条消息说"大家好"
查看我的好友列表和群组信息
```

## 使用示例（完整对话）

以下是一个在 Windows 客户端上的完整使用场景：

```
你：你好！
AI：你好！我是 ChatServer AI 智能助手，很高兴为你服务！
    我可以帮你：
    - 日常闲聊和问答
    - 搜索最新资讯（联网搜索）
    - 查看你的好友列表、群组信息
    - 查看服务器在线用户和统计数据
    - 帮你给好友发送消息

你：帮我看看谁在线
AI：当前在线的用户有：
    - zzz（ID: 393）
    - 你的名字（ID: 你的ID）
    - AI智能助手（ID: 10000）
    共 3 人在线。

你：请你帮我给我的好友393发送一条古风内容的表白信息
AI：✨ 消息已成功发送！
    发送详情：
    - 发送者：你的名字（ID: 你的ID）
    - 接收者：zzz（ID: 393）
    - 消息内容：
      > "浮世三千，吾爱有三，日、月与卿。日为朝，月为暮，
        卿为朝朝暮暮。愿执子之手，与子偕老，共度此生，
        不负相思不负卿。"
    祝您表白顺利，有情人终成眷属！💕
```

## 注意事项

1. **回复延迟**：真实 LLM 生成回复需要 5-20 秒（取决于模型响应速度和网络状况），请耐心等待
2. **联网搜索**：需要 `TAVILY_API_KEY` 环境变量（已在服务器设置）
3. **LLM 配额**：ModelScope 的 GLM-5 模型每日有 API 调用配额限制，用尽后 AI 会使用兜底回复。如需切换模型，管理员可修改 `agent_service/config.py` 中的 `MODEL_NAME`
4. **连续对话**：支持多轮连续对话，AI 会记住上下文
5. **消息长度**：单条消息建议不超过 500 字，超过可能被截断

## 故障排查

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| AI 不回复 | Agent 服务未运行 | 检查 `ps aux \| grep agent_service` |
| AI 回复"暂时无法回复" | LLM API 调用失败 | 稍后再试，或检查 ModelScope 配额 |
| 代发消息失败 | 目标用户不存在 | 确认用户 ID 是否正确 |
| 搜索无结果 | Tavily API 限制 | 换个关键词重试 |
| 回复内容是英文 | GLM-5 模型偶发 | 重新发送问题 |

## 管理员操作

### 启动 Agent 服务

```bash
cd agent_service
MODELSCOPE_API_KEY="你的key" \
TAVILY_API_KEY="你的key" \
MODEL_NAME="ZhipuAI/GLM-5" \
python3 main.py
```

### 切换 LLM 模型

编辑 `agent_service/config.py`，修改 `MODEL_NAME`：

```python
# 当前默认
MODEL_NAME = "ZhipuAI/GLM-5"
# 备用模型
# MODEL_NAME = "MiniMax/MiniMax-M1-80k"  # 最快，tool支持良好
# MODEL_NAME = "deepseek-ai/DeepSeek-R1-0528"  # 推理强，较慢
```

### 查看 Agent 日志

```bash
# Agent 日志
tail -f /tmp/agent.log

# ChatServer 日志（MCP 调用日志在此）
tail -f /tmp/server0.log
```

### 支持的 MCP 工具（共 8 个）

| 工具名 | 参数 | 说明 |
|--------|------|------|
| `chat_server_stats` | 无 | 服务器连接数、在线用户数 |
| `chat_list_online_users` | 无 | 在线用户列表 |
| `chat_get_user_info` | `user_id` | 查询用户信息 |
| `chat_get_user_friends` | `user_id` | 查询好友列表 |
| `chat_get_group_info` | `group_id` | 查看群组详情 |
| `chat_list_user_groups` | `user_id` | 用户加入的群组 |
| `chat_user_login` | `user_id`, `password` | 用户登录验证 |
| `chat_send_message` | `from_user_id`, `to_user_id`, `message` | **代发消息** |
